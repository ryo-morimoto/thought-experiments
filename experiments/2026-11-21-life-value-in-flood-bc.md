# 治水の費用便益分析に人命を入れないことは、判断をどちらに偏らせるか

- 状態: 検討中

- 更新: 2026-11-21

- 関連: 分岐元 [2026-11-21-non-detection-vs-no-change.md](2026-11-21-non-detection-vs-no-change.md)（段階B 操作4 の新しい論点）、調査メモ [research_notes/台風と防災の未解決課題/](../research_notes/台風と防災の未解決課題/)

## 問い

治水事業の費用便益比（B/C）は、守れる命を便益に含めていない。このことで、どの事業や地域が有利になり、どれが不利になるか。

問いの選び方: 前の思考実験の段階B（損失比の見積もり）で「治水の B/C は人命を便益に含めていない」ことが分かり、Claude が独立した思考実験として提案し、ユーザーが進めることを選んだ（ユーザーの判断）。

## 前提

- **B/C:** 評価期間の便益の合計を、費用の合計で割った値。どちらも社会的割引率4%で現在の価値に直す。1 を超えることが採択の条件の一つで、優先順位の参考にもなる。
- **人命を入れない:** 治水経済調査マニュアルは、死者数の推計が難しいとして人命を便益に「未計上」とする。一方、技術指針（共通編）は、防災事業の主な効果に「人的損失額」の軽減を含めることを基本とする。
- **偏らせる:** 人命を入れた場合と比べて、採択の可否や優先順位が入れ替わること。
- モード: 破壊的（「人命を入れなくても判断は大きく変わらない」という暗黙の前提を攻撃する）。ほかの候補は、構成的（人命を制約として組み込む評価の形を設計する）と探索的（人命を入れている分野と比べる）。

対立仮説:

- L1 影響は小さい。物的な被害の便益が桁違いに大きいので、順位は変わらない。
- L2 人命の危険が高く、資産が少ない地域が不利になる。便益が資産に比例するので、地方や中山間地の事業が後回しになる。
- L3（L2 の逆）入れると都市が有利になる。人口が多いほど人命の便益が大きくなり、地方がさらに不利になる。
- L4 便益ではなく制約として扱うべき（オランダの個人リスク基準のように）。B/C に入れるかどうかは問いの立て方を誤っている。
- L5 二重計上になる。避難で守る命と施設で守る命を両方の事業で数えると、便益が膨らむ。

設定の欠陥:

- 人命の値を一つの値（2.26億円）に固定している。この値は交通事故の調査から借りたもので、技術指針自身が「当面」適用するとしている。
- 同じ事業でも、避難の体制しだいで死者数は大きく変わる（真備では 349人→70人）。施設が守る命と避難が守る命を分けられない。

## 条件を変える

**操作1：実際の再評価で、採択の境目にある事業に人命を入れる。** 国交省の令和8年度予算に向けた再評価結果一覧（河川事業・直轄事業等）から77件の B/C を抽出し、人命に関わる55件（環境整備・自然再生を除く）を種類ごとに見た。

- 事業の種類で B/C の分布がはっきり分かれる。河川改修（32件）は中央値13.2・最小2.3で、境目（1.0〜1.5）は0件。ダム（9件）は中央値2.4で境目2件・1.0未満1件。砂防・地すべり（13件）は中央値1.9で境目2件。B/C 1.6以下の8件はすべてダムか砂防・地すべり。土砂災害は人命の危険に比べて守る資産が少なく、資産に比例する便益では低く出やすい（L2 の構図に合う。ただし間接的な証拠）。
- 資料に回避死者がある境目の事業に人命を入れても、**採択の基準（1）をまたぐ事業はなかった**。鳴瀬川総合開発は 1.3 → 1.37〜1.63、川辺川ダムは 0.4 → 0.38〜0.41、砂防2件はほぼ不変。実際の境目の事業は費用が数百〜1万億円と大きく、資料に書かれた回避死者は数人〜数十人で、試し打ちの仮想の事業Z とは規模が違う。
- 逆算：B/C を 0.1 押し上げるには、費用100億円あたり年0.2人の死者を防ぐ必要がある（2.26億円/人）。川辺川ダムを 1.0 にするには年145人（10億円/人でも年33人）が必要で、人命では届かない。

分かったこと:

1. **人命は、すでに評価に入っている。** 想定死者数や孤立者数は「貨幣換算が困難な効果等」の欄に、B/C とは別の数字として書かれている。人命を便益ではなく別の基準として扱う L4 の形が、実務では部分的に実現している。
2. **継続中の事業では、B/C は判断を縛っていない。** 川辺川ダムは B/C 0.4 でも、残事業の B/C（2.4）と貨幣換算できない効果を理由に継続とされている。採択の境目が効くのは、新規の採択の時点。
3. **選択の偏り。** 再評価は継続中の事業だけが対象で、B/C が低くて採択されなかった事業は一覧に出ない。L2 が問題にする「後回しにされた事業」は、この資料では見えない。

仮説への影響（段階B 時点）:

- L1（影響は小さい）: 継続中の大きな事業については支持。
- L2（資産が少なく人命の危険がある地域が不利）: 種類ごとの B/C の差という間接的な証拠だけ。直接の検証には、新規採択の評価や採択されなかった事業の資料が要る。脱落もしていない。**（訂正：操作2で、砂防はすでに人命を便益に入れていると分かったので、この間接的な証拠は撤回する）**
- L4（制約として扱う）: 実務で部分的に実現していることが分かった（「貨幣換算が困難な効果等」の欄）。
- L3・L5: この材料では判定できない。

**操作2：採択されなかった側を探す（L2 を直接確かめる）。** 判定不能。ただし前提が2つ崩れた。

- **砂防はすでに人命を便益に入れている。** 土石流対策事業の費用便益分析マニュアル（令和8年2月）は人身被害（逸失利益と精神的損害）を計上し、精神的損害を 6.01億円/人とする。操作1の「境目が砂防に集中するのは人命を入れていないから」は撤回する。人命を入れていないのは河川とダム（治水経済調査マニュアル）だけ。
- **国の人命の値は 2.26億円から 6.01億円/人に改定されていた**（技術指針（共通編）令和7年9月。砂防のマニュアルからの孫引き）。治水経済調査マニュアル（令和7年7月）は今も人命を「計測していない被害防止便益」に置くが、計測できるなら便益として評価することを「妨げない」とする。
- **採択されなかった事業は、公開資料にほとんど現れない。** 補助事業346件（新規と再評価）で B/C 1未満は0件、補助の再評価163件はすべて継続。
- **小さな河川事業では人命の重みが桁違いに大きい。** 補助の河川事業は事業費の中央値26〜30億円。境目の気仙川（B/C 1.1、浸水区域内人口3,095人）に、死亡率0.1〜1%・年1/50〜1/30・6.01億円/人を仮定すると B/C 1.24〜2.85。費用10億円の事業なら、B/C 0.8→1.0 に必要な回避死者は年1/100の災害で1回1.5人。L2 の仕組みはありうるが、実際に落ちた事業は確かめられない。

**操作3：「貨幣換算が困難な効果」は判断にどう使われているか（L4）。** 制度として機能しているが、制約（越えてはならない基準）ではなく、B/C が足りないときの補強の材料として。

- 再評価実施要領（2025年9月改定）は「総合的に評価」とし、B/C≥1 を継続の条件とする規定も人命の数値基準もない。河川の再評価は「貨幣換算が困難な効果等による評価」の視点を独立に立てる。
- 鳴瀬川総合開発では、継続の理由は「費用対効果等の投資効果も確保されていることから」で、人命の試算は「参考に」の位置づけ。川辺川ダムでは、事業全体の B/C が1未満でも、残事業の B/C と「最大孤立者数、想定死者数ともに大幅に軽減」を並べて継続の根拠にした（同年8月の監視委員会で継続を了承）。
- 人命の危険が高いことを理由に新規の採択や優先順位を上げた記録は、読んだ資料の範囲では見当たらない。補強の材料は、B/C の不足を後から正当化する方向にしか使われていない（推論）。
- 河川事業の評価手法に関する研究会（第9回・第10回、2023年）では、委員が人命を便益に計上する方向を求め、事務局は「人的被害の便益変換の手法検討」を課題に挙げた。第11回（2025年7月）の議題に人命はない。方向は「便益に入れる」で、L4 とは逆。
- オランダのデルタ計画は「2050年までに、堤防の内側のすべての人の洪水による死亡確率を年1/10万以下にする」と定める。人数によらない基準（L4 の純粋な形）で、日本の運用にはない。

**仮説への影響（操作2・3の後）:**

- L1: 継続中の大きな事業については支持のまま。継続の判断では B/C≥1 が実際の主な根拠（鳴瀬川）。
- L2: 判定不能。操作1の間接的な証拠は撤回。仕組みは小さな河川事業でありうるが、落ちた事業が公開資料に現れない。
- L4: 日本では「便益の外に置き、B/C が足りないときに補強する」形で機能。オランダ型の基準ではない。分野でも分かれる（砂防は便益に計上、河川・ダムは任意）。
- L3・L5: 判定できない（L3 は段階C で比の議論により脱落）。

## 結果を攻撃する

反例：「人命を B/C に入れると、人口の多い都市の事業が有利になり、地方の命が安く扱われる。だから入れないほうが公平だ」（L3）。人口100万人の都市の堤防と、人口2,000人の集落の事業では、人命の便益は人数に比例するので、絶対額では都市の事業が桁違いに増える。

- 成立する部分：人命の便益が人数に比例するのは事実。「命を数で比べる」構図への抵抗は、計算では否定できない価値の主張。
- 成立しない部分：B/C は費用との比。資産も人口に比例するので、都市の事業は人命なしでもすでに B/C が高く（荒川 24.0）、人命を足しても +0.4% にとどまる。相対的に効くのは資産が少ない、事業費の小さい事業の側（操作2の気仙川・費用10億円の逆算）。人命を入れないことは命の値段を 0 と置くことと同じで、中立ではない。命を数で比べたくないなら、人数によらない個人リスクの基準で守るのが筋（オランダの年1/10万）。
- 判定：「命を数で比べる構図への抵抗」は価値として生き残る。「入れると都市が有利になる」は、比で見ると逆向きなので脱落。

そのほかの攻撃:

- 「人命はすでに別欄で考慮されている」：操作3で、別欄は B/C が足りないときの補強として継続に使われているが、新規の採択や優先順位を上げる方向に使われた記録はない。採択の基準に効く経路がない。
- 人命の値：6.01億円/人（令和7年9月）でも、継続中の大きな事業の判定は変わらない。値の幅は継続中の事業についての結論を動かさない。
- 二重計上（L5）：鳴瀬川の回避41人は避難率40%が前提で、避難と施設の効果が混ざっている。治水経済調査マニュアルも人命を入れない理由に重複評価を挙げる。人命を入れるなら、避難の体制を固定して施設が上乗せで守る命だけを数える手順が要る（未確認）。
- 選択の偏り：採択されなかった事業は公開資料に現れない（補助事業346件で B/C 1未満は0件）。「判定が変わらない」のは「B/C が十分高い事業だけが一覧に残っている」からかもしれない。

答え（暫定）：河川とダムの B/C で人命を入れないことは、資産が少なく事業費の小さい事業を相対的に不利にする向きに偏らせる。継続中の大きな事業では判定を変えるほどではない。判定を変えうるのは採択の境目にある小さな河川事業だが、落ちた事業は公開資料に現れず、確かめられない。

実務者向けの主張（暫定）：河川・ダムの B/C には人命が入っておらず、砂防（6.01億円/人で計上）と扱いが分かれている。事業費の小さい河川事業では、人命を入れるかどうかで採択の可否が変わりうる。境目の事業では、別欄の想定死者数を採択の判断に明示的に使うか、人数によらない個人リスクの基準と併せて判断すべき。

選択肢（どれを採るかは「命を数で比べることへの抵抗」をどれだけ重んじるかという価値判断。まだ選んでいない）:

- M1（生存）：河川・ダムでも人命を便益に入れる（砂防と揃える）。避難との二重計上を避ける手順が要る。
- M2（生存）：便益には入れず、人数によらない個人リスクの基準を別に置き、満たさない地区の事業を優先する。
- M3（条件付きで生存）：現状（別欄に記載）を続け、別欄が採択でどう使われたかを記録・公開する。偏りは残る。
- 脱落：「入れると都市が有利になる」（比で見ると逆向き）、「別欄にあるから問題はない」（採択の基準に効く経路がない）。

完了条件：未達。従来の判断と結論が食い違う具体例（人命を入れれば採択された河川・ダム事業）が公開資料で見つからない。状態は「検討中」のまま。
