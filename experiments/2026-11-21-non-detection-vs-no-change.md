## 問い

気候の変化が統計的に検出されていないとき、防災の判断（治水計画、高潮の想定、保険、避難の体制）で「変化はない」とみなして、現状の想定を維持してよいか。

問いの選び方: ユーザーが「社会的に価値の高い思考実験」を求め、業界の課題と未解決論文の調査から Claude が候補を5つ順位付けし、ユーザーがこの問いを選んだ（ユーザーの判断）。

## 前提

- **検出:** IPCC の定義に従い、ある統計的な意味で変化があったことを示すこと（原因は問わない。原因は「寄与」として別に扱う）。誤検出を抑える設計で、典型的には有意水準5%。
- **防災の判断:** 見逃し（変化を想定せずに被害を受ける）と空振り（想定したのに変化がなく費用が無駄になる）の損失が非対称な判断。
- **扱ってよい:** 損失の非対称を考えたうえで、判断の向きを誤らせないこと。
- 最初の思考実験の枠組み（健全性と完全性の非対称）を社会的な判断に移したもの。科学的な検出は健全性（誤って「ある」と言わない）を、防災は完全性（見落とさない）を優先する。
- モード: 破壊的（「未検出なら現状の想定を維持してよい」という推論を攻撃する）。ほかの候補は構成的（弱い証拠を使う判断のルールを組み立てる）。

対立仮説:

- D1 扱ってよい。長い記録で検出されないこと自体が、変化が小さい証拠になる。
- D2 扱ってはいけない。証拠がないことは、ないことの証拠ではない。
- D3 検定の力しだい。判断に効く大きさの変化を見つけられる力があれば、未検出は情報になる。
- D4 基準を用途ごとに分けるべき。防災では見逃しを減らす弱い基準を使う（Knutson ら 2019 の例）。
- D5 観測をやめて予測を使うべき。治水の降雨量の倍率はこの方式だが、高潮の想定は違う。

設定の欠陥:

- 「検出されない」を二値で扱っているが、IPCC は確信度を段階で表している。
- 判断する人が未検出を「変化なし」と読んでいること自体が経験的な主張。高潮の手引きは想定する台風を固定しているが、理由として「未検出だから」と書いているわけではない。

## 条件を変える

**操作1：指標を動かす（発生数 → 接近数 → 上陸数）。** 3つとも「未検出」だが、判断に直接効く指標ほど検定の力が弱い。80%の確率で見つけられる最小の変化は、発生数で20%、接近数で31%、上陸数で65%。上陸数の95%信頼区間は −52%〜+39% で、「未検出」はほとんど何も語らない。

**操作2：損失の非対称を動かす。** 行動は「現状維持」か「対策」。判断に効く変化（増加10%以上）が起きているのに維持したときの損失を L_miss（見逃し）、変化がないのに対策したときの費用を C（空振り）とすると、維持が正しいのは P(判断に効く変化 | データ) < C/L_miss のとき（平たい事前分布・正規近似）。

- 同じ「未検出」でも、維持が正しい損失比の上限は、発生数で約1500、接近数で7.1、上陸数で4.2。日本への被害に近い指標ほど、軽い非対称で対策が正しくなる。
- 仮想のシナリオ（推定0、増加方向で t=+1.0、t=+1.78。どれも未検出）でも、判断は損失比によってばらばらに分かれる。判断を決めているのは検出の有無ではなく、推定の向き・判断に効く変化が起きている確率・損失比の3つ。
- 「両側 p<0.05 で検出されたら対策」というルールは、平たい事前分布の下では L_miss/C ≈ 1.03、つまり見逃しと空振りを同じ重さに置くことと同じ（暗黙の損失比）。
- 発生数で維持が正しくなるのは、未検出だからではなく、推定が減る向きだから。

**操作3：制度の側の理由を原文で突き合わせる（D5）。** 高潮浸水想定の手引き（避難のための想定）は、想定する台風を過去最大級に固定しているが、理由は「未検出だから」ではない。最悪の事態を描くため（三大湾で確率年 1/500〜1/数千年）であり、気候変動を入れないのは制度（「直ちに…反映させる制度とはなっていない」）と研究の未成熟による。治水計画の提言（施設の計画規模）は、物理的な根拠・観測された変化・遅れたときの費用を挙げて予測を採用した。海岸保全の提言は、平均海面水位に1906〜2019年の長期で上昇傾向がない（未検出）にもかかわらず、予測を採用している。

**操作4：損失比を実際の値に近づける。** 公開の一次資料から、見逃しの損失と空振りの費用を見積もった。損失比の桁は用途によって2桁以上違う。

- 避難: 約20〜3,500。人命の評価額は国の値の下限（2.26億円/人）、避難1人1回の費用は上限寄りの仮定（1〜5万円）でも、上陸数・接近数のしきい値（4.2・7.1）を大きく超える。
- 治水の施設計画: 事業全体の費用便益比（B/C）で代用すると約2.5〜24。鵡川（2.5）はどの指標でも維持の範囲、荒川（24.0）は上陸数・接近数の基準なら対策。判断は河川ごとに分かれる。
- 新しい論点：治水の B/C は人命を便益に含めていない。真備の規模（回避279人）を 2.26億円/人で入れると便益に約630億円が加わり、鵡川級の事業費（223億円）を上回る（推論）。

**操作5：強さの指標で確かめる（RSMC ベストトラックを取り込み）。** 強い台風の割合は、発生数と逆の状況だった。

- 最低気圧 ≤930hPa の割合: 推定ほぼ0（t≈0.1〜0.2）。精度が低く、維持が正しいのは損失比 2.4〜2.8 未満だけ（シナリオ B に近いが精度は悪い）。
- 最大風速 ≥85kt（非常に強い以上）の割合: 増加方向で t≈0.8。維持が正しいのは損失比 1.7 未満（B と C の間）。
- 最大風速 ≥105kt（猛烈な）の割合: 1977〜2025年で t=1.05（シナリオ C）。1987〜2025年では t=3.11 で検出、相対 +119%（95%区間 +44〜+195%）。
- 同じ「未検出」という言い方でも、発生数（推定が減る向き。上限約1500）と強さ（増加方向。上限1.0〜2.8）では判断の向きが逆になる。
- 揺らす要因：気圧で定義すると傾向がなく、風速で定義すると増える食い違いは、風速を推定する手順の変化を疑わせる（ベストトラックの不均質）。1987年は航空機観測が終わった直後。7通りの定義・期間で検定したので選択の効果を割り引く必要がある。機関（JMA と JTWC）で強さの評価が違う。

**操作6：強さの記録は均質か（操作5を攻撃する）。** 同じ中心気圧の帯での最大風速の平均は、1987〜2006年に比べて2015〜2025年が 3.5〜4kt 高い。気圧と風速は同じ強さを表す量なので、風速を推定する手順の変化を示す。気圧で数え直すか、年代ごとのかさ上げを差し引くと、猛烈な台風の割合の増加（+119%）の 78〜89% が消え、有意でなくなる（t=0.33〜0.55）。TyRA（Ito ら 2026、査読前）と、それが引く Kawabata ら（2023）も、気象庁の記録が1980年代後半〜2000年代半ばに強い台風を少なめに記録していたことを指摘している。公式の修正履歴（335件）は、この不均質をさかのぼって直していない。

- 操作5の「1987年以降の猛烈な台風の増加は検出された」は、記録の不均質による見かけの検出だった可能性が高い。強さの指標はどれも「推定ほぼ0で精度が低い」（シナリオ B）に戻る。それでも、現状維持が正しいのは損失比が約2〜3未満のときだけで、D1 の脱落と D4 の支持は変わらない。
- 新しい論点：提供者自身の記録の年代による不均質は、修正履歴に現れない。最初の思考実験の A1（提供者が一つしかないため、誤りの原因が共通）が、データの中身の不均質として現れた例。

**仮説への影響（段階B 時点）:**

- D1（未検出なら変化なしとして扱ってよい）: **脱落**。操作2で、維持が正しいかは未検出かどうかで決まらない。操作3で、どの制度資料も未検出を根拠にしておらず、海岸保全の提言は未検出でも予測を採用している（反例）。
- D2（未検出は何も語らない）の強い形: **脱落**。発生数では、未検出のデータが「増加はほぼない」と強く語っている。
- D3（検定の力しだい）: **修正して生存**。正しくは「判断に効く変化が起きている確率と損失比しだい」。操作4・5で、実際の損失比と強さの指標の値で裏付けた。
- D4（基準を用途ごとに分ける）: **さらに強く支持**。検出の基準は暗黙に損失比を約1と置いているが、実際の損失比は避難で 10¹〜10³、施設で 10⁰〜10¹ と、どの用途にも合わない。治水と海岸保全の提言は遅れの費用を明示的に論じている。
- D5（観測をやめて予測を使う）: **修正**。「用途と制度ごとに、基準を切り替える時期が違う」。確信度は違いの説明にならない（同程度の不確かさで判断が分かれている）。

## 結果を攻撃する

反例：「損失比が分からないなら、検出の基準（損失比 ≈ 1）に頼るのが一番中立ではないか」。ある県の治水担当者は、損失比を3と置けば維持、30と置けば対策になる。数字を決めるのは自分なので、科学が検出したときだけ動くほうが説明がつく、と主張する。

- 成立する部分：検出の基準は事前に公開された合意済みのルールで、誰が使っても同じ答えになる（手続きの正当性）。空振りの費用は他の安全投資を押しのける（機会費用）。見逃しの重さは予算を増やしたい側に都合よく水増しされ得る（モラルハザード）。
- 成立しない部分：検出の基準は損失比 ≈ 1 と同じで、操作4 の推定範囲（治水 約2.5〜24、避難 約20〜3,500）のどれよりも小さい側の端にある。中立な点ではない。損失比を決めずに済ませる方法はなく、検出の基準を使えば1を黙って選んだことになる。手続きの正当性は、用途ごとの損失比を事前に公開の手続きで決めても得られる（治水の提言はこの方向）。
- 判定：「手続きの正当性」「機会費用」は生き残る。「検出の基準が中立」は脱落。

そのほかの攻撃:

- 平たい事前分布の恣意性：気候モデルの予測を事前分布にすると、強さの指標は対策側に動き、発生数はほぼ動かない。結論の向きは変わらず、強まる（推論）。
- 指標の選択：結論の核はどの指標でも成り立つ。猛烈な台風の +119% は、操作6で記録の不均質による見かけの増加の可能性が高いと分かった。それでも強さの指標で維持が正しいのは損失比が約2〜3未満のときだけなので、核は動かない。
- 損失比の推定の荒さ：避難は下限側の仮定でもしきい値を超える。治水は河川ごとに分かれ、推定の精度に依存する。
- 繰り返しの判断：毎年見直せるなら後悔は小さい。ただし後戻りしにくい施設投資では遅れの費用が積み上がる。避難は毎回やり直せるが、見逃しは取り返せない。

## 結論

| 前提 | 種類 |
| --- | --- |
| 検出の基準は、損失比 ≈ 1 と置くことと同じ（平たい事前分布の下） | 論証 |
| 判断を決めるのは、検出の有無ではなく、推定の向き・確率・損失比 | 論証（実データで裏付け） |
| 発生数は減る向き。強さの指標は推定ほぼ0で精度が低い | 経験的（確認済み） |
| 猛烈な台風の +119% は、記録の手順の変化による見かけの増加の可能性が高い | 経験的（計算で確認。根拠の論文は査読前） |
| 損失比は、避難で 10¹〜10³、治水で 10⁰〜10¹ | 経験的（仮定を含む推定） |
| 用途ごとの損失比を、誰がどう決めるべきか | 価値判断 |

**答え:** 「科学的に検出されていない」は、防災で「変化なし」として扱う根拠にならない。検出の基準をそのまま使うと、見逃しと空振りを同じ重さに置くことになり、防災のどの用途の実際の損失比よりも小さく、見逃しの側に偏る。

選択肢（どれを採るかは、正統性・透明性・頑健性のどれを重んじるかという価値判断。まだ選んでいない）:

- E1（生存）：用途ごとの損失比を公開の手続きで事前に決め、それで判断する。
- E2（条件付きで生存）：検出の基準を使い続け、損失比 ≈ 1 という含意を明示する。透明にはなるが偏りは残る。
- E3（生存）：損失比を幅で示し、どの値でも結論が変わらない判断だけを確定させる。避難は「対策」に確定し、治水は河川ごとに保留になる。
- 脱落：「検出の基準が中立」（損失比1はどの推定範囲よりも小さい端）、D1「未検出なら変化なし」、D2 の強い形。

### 試し打ちの計算（検定の力）

[data/jma-typhoon-generation/generation.csv](../data/jma-typhoon-generation/generation.csv) の年間発生数（1951〜2025年、75年）に最小二乗法で直線を当てはめた（`python3`、標準ライブラリだけ）。出典：気象庁ホームページ（https://www.data.jma.go.jp/typhoon/statistics/generation/generation.html ）をもとに筆者が計算。

```
n=75 傾き=-0.0439/年 (75年で -3.25個) 標準誤差=0.0246 t=-1.78
残差の1次自己相関=0.17
5%で有意になる最小の傾き: 0.0482/年 = 75年で 3.6個（平均26.0の 14%）
検出力80%で見つかる最小の傾き: 0.0688/年 = 75年で 5.1個（平均26.0の 20%）
傾きの95%信頼区間: -0.0921〜0.0043/年 = 75年で -6.8〜+0.3個
```

自己相関（0.17）は考慮していないので、本当の不確かさはこれより少し大きい。

### 調査で見つけた具体（出典は調査メモ）

- 国土交通省「高潮浸水想定区域図作成の手引き」Ver.2.11 は、想定する台風を室戸台風の中心気圧 911.6hPa と伊勢湾台風の経路・速度に固定し、気候変動の将来予測を「直ちに…反映させる制度とはなっていない」とする（[science_open_problems.md](../research_notes/台風と防災の未解決課題/science_open_problems.md)）。

- Knutson ら（2019）は、従来の厳しい基準では著者の意見が割れたため、見逃しを減らす弱い基準で評価し直した（[science_open_problems.md](../research_notes/台風と防災の未解決課題/science_open_problems.md)）。
