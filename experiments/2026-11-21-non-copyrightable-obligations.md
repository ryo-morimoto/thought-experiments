# 著作物でないデータに、ライセンスの義務は及ぶか

- 状態: 結論済み
- 開始: 2026-11-21
- 更新: 2026-11-21（さかのぼって記録）
- 関連: [前の問い：データポリシーの規約準拠は証明できるか](2026-11-20-data-policy-provability.md)、[data-policy.toml](../data-policy.toml) の `[terms]`・`[terms_policy]`・`[third_party]`

## 問い

江戸川区「公営駐車場一覧」（名称と ID だけの3行）のような著作物に当たらないかもしれないデータで、CC BY と東京都の利用規約が定める義務に、私は縛られるのか。

## 前提

- **著作物:** 「思想又は感情を創作的に表現したもの」（著作権法2条1項1号）。データの集まりは、選び方か体系的な構成に創作性があるときだけ保護される（12条の2）。日本には EU のようなデータベース権がない。
- **義務の出どころ** を3つに分ける。①著作権の許諾の条件（CC BY）、②利用規約という契約、③私自身の表明（`DATA_POLICY.md`）。③は定義上いつも及ぶので、問いは①②に絞る。
- モード: 破壊的（「外部データには必ずライセンスの義務がある」という前提を攻撃する）。

対立仮説:

- R1 及ばない。著作物でなければ①の条件は空振りする。
- R2 契約として及ぶ。著作物かどうかに関係なく、②が契約として成立していれば残る。
- R3 法ではなく規範として及ぶ。
- R4 完全に及ぶ。標準の項目に沿って選んで並べた一覧は編集著作物になり得る。
- R5 事前には決まらない。著作物かどうかは事後に裁判所が判断するので、安全側に従うのが合理的。

試し打ち: 選び方の創作性を動かすと、①の義務は線を越えたところで急に現れ、その線はこちらから引けない（R5 に有利）。②は創作性と無関係（R2 は別の軸）。

## 条件を変える

1. **契約が成立する条件（R2）。** 取得の経路（私たちは CSV の URL を直接取得し、規約は表示されていない）、対価の有無（無償なので「取引」かが疑わしい）、当事者（規約は東京都、データは江戸川区）。どれも成立しにくい方向に振れ、**R2（無条件）は脱落**。ただし反転させる条件として、私たち自身の記録（規約を `license_url` に指定し、「確認した」と記録すること）が、同意の意思表示に当たり得る（逆説）。
2. **同意を示さずに準拠を記録できるか。** 書き方を「参照した規約」に変えても、規約を知って使えば民法527条の意思実現で同意とみなされ得る（脱落）。規約を読まないのは表明2と衝突する（脱落）。根拠を CC BY だけにして規約を参照扱いにし、留保を書く案は不確定。違いが出るのは**求償条項**というリスクの範囲だった。選択肢は S1（承知で受け入れる）、S2（CC BY だけを根拠に留保する）、S3（求償条項のある規約は使わない）。
3. **前提を確かめる。** 東京都の規約第6条は、利用者による第三者の権利侵害で提供者に生じた費用を、利用者が弁償すると定める（証拠の写しから原文を確認）。提供者側の誤表示のリスクが、この条項で利用者に移る。民法522条・527条・548条の2・93条は e-Gov の API で原文を確認した。デジタル庁の解説によれば、政府標準利用規約は第2.0版から、著作物でないコンテンツには規約を適用しないと明記した（「著作権を根拠としない条件を課すことはガイドラインの考え方に沿わない」）。
   → 答えは**データの性質ではなく、どの規約で提供されているか**で分かれる。R5 は「データを見ても決まらず、規約を見て決まる」に修正。R1 は国の規約については提供者自身の見解で支持された。

## 結果を攻撃する

PDL1.0 にも、第三者の権利の処理を「利用者の責任で」とする条項（1.2）と、提供者の免責（1.6）がある。これも求償条項と同じ種類のリスクではないか。

反例となる思考実験: PDL1.0 の白書に民間の写真家の写真が明示なしで載っていて、私が再配布し、写真家に訴えられた場合を考える。私が写真家に負う責任はどちらの規約でも同じ（著作権法上の責任）。違いは、写真家が提供者を訴えたときの提供者の費用を私が負うかどうかで、それを負わせるのは求償条項だけ。PDL の 1.2 と 1.6 は、法律がもともと置いている責任の配分を確かめ、提供者への請求を封じるだけ（法的評価は未検証）。

副次的な発見: 第三者の権利のリスクは、数値データではなく、写真・文章・地図などの**著作物の部分**に集中する。

## 結論

| 前提 | 種類 |
| --- | --- |
| S3 が問題にするのは「法律上はない責任が新たに加わること」 | 定義上 |
| PDL の 1.2 と 1.6 は新しい責任を加えず、提供者への請求を封じるだけ | 論証 |
| PDL に弁償・求償の条項はない。提供者自身が「権利処理を行っていないものが多数存在する」と認めている | 経験的（原文で確認） |
| 答えは規約の種類と、データが著作物の部分を含むかで決まる | 論証 |
| 免責の有効性、同意みなしで契約が成立するか | 未検証 |

採った方針（ユーザーの判断）:

- **S3:** 求償条項のある規約のデータは使わない。江戸川区のデータは、東京都の規約にも区自身の規約にも求償・弁償の条項があったので削除した。
- 著作物でないデータにも条件を課す規約は許可する（条件を守ればよい）。
- **案 C:** 規約に第三者の権利の処理を誰が負うかを記録し、著作物の部分を含むデータでは、提供者が権利処理済・自作と明示した証拠を必須にする。

脱落: R2（無条件）、書き方だけ変える案、規約を読まない案、「利用者の責任で」の条項まで拒否する案（国のオープンデータがほぼ全部使えなくなる）。

## 経過

- 2026-11-21 段階A（問いの設定と試し打ち）。
- 2026-11-21 段階B: R2 を掘る → 逆説 → 同意を避ける方法 → 前提の検証（規約第6条、民法、政府の解説）。
- 2026-11-21 S3 を選び、`data-policy.toml` に `[terms]` と `[terms_policy]` を追加。江戸川区のデータを削除。
- 2026-11-21 段階C（PDL1.0 への攻撃）。S3 を維持し、案 C を `[third_party]` として実装。
