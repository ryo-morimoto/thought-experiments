# 攻撃者が入力を選んで問い合わせを繰り返すと、ORB の判定から秘密はどれだけ漏れるか

## 問い

前の思考実験は、攻撃者が本文に中身を混ぜ込めると ORB の判定は攻撃者が選ぶ述語になり、問い合わせを繰り返せば秘密を 1 ビットずつ読める、という反論を議論で受け入れただけで、動かしていない。モデルを 2 つの実行で並べ（自己合成）、攻撃者が混ぜ込む部分を選び k 回問い合わせる形で、秘密のどれだけが観測から決まるかを TLC で数える。漏らすものの一覧は、どの形なら「攻撃者が選べない秘密の固定した関数」になるか。

問いの出し方（ユーザーの判断）: 作業の木の効きが高・中の節がなくなるまで進める（/goal）。Claude は、互いにぶつからない作業の束に分けて並行で進め、この記録はその束の 1 つ。

## 前提

- ORB は Fetch の d7fc0fd に無く、PR #1442 の拡張として扱う。
- モード: 破壊的（漏れの量を測る）。

対立仮説:

- R1 1 ビットずつ漏れる。k 回で k ビット決まり、秘密の長さの回数で全部決まる。
- R2 漏れは限られる。ORB の判定は、混ぜ込める位置によっては秘密に依らない。
- R3 一覧は書ける。攻撃者が選べる部分を除いた述語に限れば、固定した関数になる。

設定の欠陥: 本文の抽象（JS として読めるか）が、実際の嗅ぎ分けを表しきれない。

## 条件を変える

subagent が、本文を秘密のバイトと攻撃者が反射させるバイトの並びとして写し、ORBExtension.tla の判定を変えずに使い、2 つの実行を並べる形と、攻撃者が判断の木（深さ k）で問い合わせを選ぶ形で、問い合わせのあとに見分けられる秘密の類の数を TLC で数えた（[selfcomp/](models/site-isolation/selfcomp/RESULTS.md)、SelfCompORB.tla、SelfCompRun.tla）。筆者は報告を読んだ。

**抽象**: 本文は A0 s1 A1 … sN AN。秘密の 1 ビットは " のバイト、0 は文字。Ai は攻撃者が反射させるもの（空、"、/、改行。A0 は画像と嗅がれる g もありうる）。制御は 3 段階（無し、両端だけ、秘密の間にも挟める）。ORB の 15 段目（JS として読めて JSON でない）は字句の水準で確かめる（文字列、// の注釈、文字列の中の生の改行は構文の誤り。JSON は 1 つの文字列の字句）。最初の 1024 バイトの嗅ぎ分けは、本文が g で始まるときだけ画像で、攻撃者だけに依る。ヘッダーは ORB-NOTES の漏れる組（MIME が阻止の型、nosniff 無し、200）、メディアの要求の状態は攻撃者が選ぶ。字句の読みは本当の JS より狭いので、数はこの小片の集合での下限。

（理想の 1 ビットの判定器なら 2 の k 乗の類。）

**判定を宣言しない・する**: SpecIsolation の Declared のまま（宣言しない）では、どの制御の段階でも NoUndeclaredLeak は崩れる。判定の 1 ビットを宣言する（ORB-NOTES の形）と成り立つが、定義で成り立つだけで、判定が秘密だけの関数になるのは攻撃者の制御が無いときだけ。

**漏らす一覧の形**（区切った開示として N = 2〜4 で、自己合成の状態機械で N = 3・k ≤ 3 で確かめた）

- 成り立つ: 攻撃者の中身が無いときの、サーバー自身の本文の判定（メディアの要求の状態ごと）。同じく、サーバー自身の本文の嗅ぎ分けの類と JS として読めるか。15 段目を外した ORB（嗅ぎ分けだけ）は、何も宣言しなくても、どの制御の段階でも成り立つ。
- 崩れる: 何も宣言しない。嗅ぎ分けの類だけ。攻撃者が両端か間を制御するときの、固定した本文の判定か嗅ぎ分けと読み。反例: 秘密 000 と 011 はそれだけでは同じ判定だが、A2 = /、A3 = " を挟むと、本文 aa/a" は不透明、a"/"" は誤り。
- ORB は攻撃者のバイトとサーバーのバイトを見分けないので、「攻撃者の中身が無い」は ORB が守れる条件ではなく、脅威の想定の制限。

読み取れること:

- R1（1 ビットずつ漏れる）が、攻撃者が秘密の間にも挟めるときに当たった。N 回の問い合わせで N ビットの秘密が全部決まる。前の思考実験で議論で受け入れただけの反論を、動かして確かめた。
- R2（漏れは限られる）は、制御が無いとき（k によらず 1 ビット）に当たり、両端だけのときに一部当たった（6 の類で止まる。小片を増やせば上がりうる）。
- R3（一覧は書ける）は、攻撃者の中身が無いか、15 段目を外したときだけ当たった。
